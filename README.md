# 王者荣耀出装对比系统 ｜ 底层算法与战术知识库

- **仓库核心交付**：开源王者荣耀底层物理算分引擎、装备合成拓扑与专供 NotebookLM / RAG 深度检索的 6 大战术知识库；
- **推演实验室交付**：为保证极致体验与实时数据维护，可视化推演沙盒采用云端持续交付，无需配置本地环境，直接通过全球 CDN 访问：[https://wzry.aodilab.com](https://wzry.aodilab.com) ｜ 微信搜索「**王者出装箱**」小程序。

---

## 一、 我们做这个网站要解决什么问题？

很多玩家在备战或实战中，常常遇到出装二选一的纠结：
- *“这把逆风，我最后一件到底补碎星锤还是补破军？”*
- *“打野走半肉穿透流伤害够不够秒后排？还是直接走全肉流抗伤更稳？”*
- *“辅助是出近卫+救赎保后排，还是出极影+奔狼打强开？”*

传统助手通常只给出一套静态出装，玩家在面临不同方案时，往往**无法全方位评估出装的实际优劣**。  
这个网站本质上是一个**出装对比平台**。我们引入 133 位英雄全分路共 505 套王者官方推荐出装作为参照基准，支持将任意两套出装（含 30 颗自选铭文）并排横向对比，通过实战伤害、野区清理、多维续航、技能冷却、面板属性与机制差异 6 个维度的定向分析，为玩家提供评估出装优劣的直观物理数据。

## 三、 各大对比板块的具体设计

### 1. 通用基础板块

#### 【板块一】实战连招与伤害对决
- **设计理念**：考虑到前排坦克和后排射辅的护甲不同，伤害计算不能单纯只看攻击力数值，必须把目标的护甲、以及我方的物理/法术穿透（固定穿透与百分比穿透）综合带入计算。
- **计算逻辑**：引入游戏底层抗性减免公式：
  $$\text{受击净伤害} = \text{原始总伤害} \times \frac{602}{602 + \text{目标实际抗性}}$$
  （目标抗性优先扣减固定穿透，再扣减百分比穿透）。
- **双靶物理基准**：
  - **中射靶（350 物抗 / 180 法抗）**：测算切后排脆皮的净掉血；
  - **坦克靶（1000 物抗 / 600 法抗）**：测算打前排坦克时穿透装的实际收益。
- **附：【板块一专属下钻视窗】各技能详细物理拆解与效果对决**：
  - **与板块一的关系**：微观拆解与补充。主面板板块一看的是连招打完的**总伤害与总控制时长**；点击进入二级视窗后，则把普攻、1技能、2技能、大招拆开为独立卡片，逐行比对**单发技能的实际净伤害、控制时长、回血量与实际冷却**，看清总伤害具体差在哪个技能上。

#### 【板块二】实战生存与多维续航对决
- **设计理念**：承伤能力不能只看血量上限，还要结合护甲计算实际承伤；同时吸血和技能回血在不同血量状态下效果不同，需要多状态对比。
- **测算依据**：
  - **物理有效生命（EHP）**：$\text{最大生命} \times [1 + (\text{抗性} / 602)]$，衡量实际能吸收多少物理伤害；
  - **多血线动态续航模型**：包含常态脱战自然回血与普攻打靶吸血，并带入满血、半血、20% 残血三档状态，对比不同血量下的技能回血和吸血增益。

#### 【板块三】各技能实际冷却时间
- **设计理念**：技能冷却时间不仅看装备缩减百分比，还要结合各技能的基础 CD 和 40% 的冷却上限，算出每个技能实际的冷却秒数。
- **测算依据**：英雄 15 级技能基础 CD，结合装备和铭文缩减，受冷却上限 40% 约束，测算两套出装下每个技能的实际冷却时间。

#### 【板块四】核心面板属性对决
- **设计理念**：横向对比两套出装在满级、满铭文、满装备状态下的 12 项硬性基础属性。
- **涵盖的具体数据项**：
  1. 最大生命值
  2. 物理攻击 / 法术攻击
  3. 物理防御（附带物理免伤率 %）
  4. 法术防御（附带法术免伤率 %）
  5. 移速
  6. 攻击速度
  7. 暴击率 / 暴击效果
  8. 物理穿透（固定穿透 + 百分比穿透）
  9. 法术穿透（固定穿透 + 百分比穿透）
  10. 冷却缩减 %
  11. 物理吸血率 / 法术吸血率
  12. 每 5 秒回血数值

#### 【板块五】核心装备机制差异
- **设计理念**：自动过滤两套出装中重复的共有装备，只对比两套出装各自独有的装备效果与被动机制。
- **呈现逻辑**：如方案 A 独有【制裁】重伤减疗，方案 B 独有【冰痕】减速留人，方便玩家对比装备的功能特性。

### 2. 分路专属板块

#### 【打野专属】野区清理与控龙耗时
- **设计理念**：针对打野分路，对比两套出装的刷野速率与控龙斩杀线。
- **测算依据**：
  - **红蓝 BUFF 争夺**：基准血量 6500，物抗 240 / 法抗 180，测算刷怪耗时；
  - **史诗级大龙（暴君/主宰）**：基准血量 24000，物抗 360 / 法抗 280，测算单刷大龙耗时与惩击安全斩杀线。

#### 【辅助专属】团队协同与增益效果
- **设计理念**：针对辅助分路，对比两套出装对团队的增益效果与主动保人/开团能力。
- **测算依据**：
  - **团队光环收益**：对比两套出装给周围队友提供的双抗、移速、攻速或冷缩加成；
  - **主动装备数值**：对比救赎之翼群体护盾量、奔狼纹章爆发加速比例与持续时长、形昭之鉴探草减速范围等具体实战收益。

## 四、 知识库构建与算法运行

本项目核心算法与知识库构建脚本基于 Python 3.8+ 开发：

```bash
# 1. 安装环境依赖
pip install -r requirements.txt

# 2. 重新编译生成专供 NotebookLM / RAG 的 6 大纯净战术知识库 (output/)
python build.py --kb
```
