## 一、 项目范围说明

本项目面向玩家备战选装场景，将静态推荐方案转化为可量化的面板与对局数据对比：

- **开源仓库（当前仓库）**：开放 133 位正式服英雄的基础属性与技能库、121 件装备真值与合成树、30 颗五级铭文数值字典（`config/`），基础面板与装备合成属性计算模块及知识库构建脚本（`src/`、`build.py`），以及构建生成的 Markdown 知识库（`output/`）与深度实测攻略（`docs/guides/`）。
- **在线端与小程序端（`wzry.aodilab.com` / 微信「王者出装箱」）**：收录 133 位英雄与 507 套官方推荐基准，提供两套出装与铭文的交互式并排对决，涵盖连招伤害对比、生存续航、技能冷却、清野耗时、面板属性横比及独有被动提示。

## 二、 基础属性与减伤换算口径

基础数值测算依据王者荣耀正式服通用规则：

1. **穿透先后顺序与抗性减免**：伤害计算优先扣除固定物理/法术穿透，再按百分比穿透比例折算目标剩余实际抗性，之后代入减免公式：

   $$\text{受击净伤害} = \text{原始总伤害} \times \frac{602}{602 + \text{目标实际抗性}}$$

2. **物理 / 法术有效生命（EHP）**：综合最大生命与防御免伤率评估承伤能力：

   $$\text{物理有效生命 (EHP)} = \text{最大生命} \times \left(1 + \frac{\text{物理防御}}{602}\right)$$

3. **冷却与攻速规则**：英雄 15 级技能基础冷却与铭文、装备冷却缩减叠加，严格执行 `40%` 冷却缩减上限；普攻频率按 S30 赛季后移除离散攻速阈值档位的连续线性机制与英雄 1 级自带攻速换算。

## 五、 本地构建说明

公开仓库基于 Python 3.8+ 运行：

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 构建公开版 Markdown 战术知识库 (output/)
python build.py --kb
```
