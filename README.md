# 王者荣耀出装推演沙盒与战术知识库

在线使用：[https://wzry.aodilab.com](https://wzry.aodilab.com)  
微信小程序：微信搜索「**王者出装箱**」  
离线版本：下载根目录的 `sandbox.html` 双击即可在浏览器离线运行。

---

## 项目介绍

本项目主要解决两个需求：
1. **局内配装推演沙盒**：单文件网页工具，支持 133 位国服英雄的六神装与 30 颗五级铭文自由搭配，实时计算满级 15 级真实面板属性（攻击、法强、双抗、移速、攻速阈值与免伤率），并自动诊断装备冲突。
2. **战术知识库（供 AI 检索 / NotebookLM）**：抓取并清洗官方最新接口数据，生成排版规整的 Markdown 文档，涵盖技能成长数值、装备合成树、克制关系、铭文配置与连招手法。

---

## 核心功能

### 1. 配装推演沙盒 (`sandbox.html`)
- **英雄与分路选择**：收录国服 133 位英雄（含新英雄王维及最新技能改动），按职业分类，支持在进推演室前先选择对局分路（如对抗路/打野）。
- **六神装装配**：自由选配 121 件局内装备，自动识别小件升级关系，支持一键清空与加载官方推荐装。
- **五级铭文自由混搭**：红、蓝、绿各色 10 颗自由搭配（例如 7异变 3祸源 10鹰眼 5狩猎 5隐匿），属性实时汇总累加。
- **属性计算与冲突诊断**：
  - 计算公式对齐游戏底层：英雄 15 级基础属性 + 装备面板 + 铭文数值。
  - 自动检测【强击】互斥（如宗师与冰痕）、【神速】双鞋减速不叠加、唯一被动合并与打野刀绑定惩击。
- **战术协同与连招参考**：展示攻防倾向评分、英雄克制搭档、情境连招口诀（起手/消耗/团战切入）。
- **界面体验**：支持深浅外观切换，手机端自动切换为底部抽屉卡片，底部带有可折叠的英雄出装速查目录。

### 2. 结构化知识库 (`output/`)
Markdown 文件按序号编排，可直接全选拖入 Google NotebookLM 或本地 RAG 知识库：

- `01_全英雄技能数值与等级成长库.md`：133 位英雄技能 1~6 级数值、冷却、消耗与加成公式。
- `02_英雄战术克制与阵容搭档拓扑.md`：最佳搭档、对线克制与反制分析。
- `03_五大分路定位与实战出装思路.md`：各分路主流打法与出装方案。
- `04_全装备属性与合成升级图谱.md`：121 件装备基础属性、合成路线与唯一被动说明。
- `05_全铭文图鉴与英雄搭配方案.md`：全五级铭文属性与 133 位英雄官方推荐套组。
- `06_峡谷战场机制与宏观运营规则.md`：S45 赛季机制、新技能与野区规则。
- `07_S45官方推荐全英雄全分路出装与铭文大全.md`：官方全英雄、全分路推荐出装与铭文速查。
- `08_全英雄实战连招口诀与操作解析大全.md`：全英雄起手、连招口诀与团战操作细节。

## 快速使用

### 环境要求
Python 3.8+

```bash
pip install -r requirements.txt
```

### 构建命令
统一通过 `build.py` 调度：

```bash
# 生成全套知识库与沙盒网页
python build.py --all

# 仅生成沙盒网页 (输出 sandbox.html 与 dist_pages/index.html)
python build.py --sandbox

# 仅更新 SEO 资产 (robots.txt 与 sitemap.xml)
python build.py --seo

# 导出出版级全彩矢量 PDF 手册
python build.py --pdf
```

## 目录结构

```text
├── build.py                   # 统一构建入口
├── sandbox.html               # 单文件配装推演沙盒 (可离线双击打开)
├── config/                    # 静态字典与英雄补丁
├── src/
│   ├── core/                  # 数据采集、清洗与校验
│   └── builders/              # 知识库、沙盒与 PDF 生成逻辑
├── templates/                 # 前端模板 (HTML / CSS / JS)
├── output/                    # 产物：Markdown 知识库与 PDF 手册
└── dist_pages/                # 线上部署目录 (Cloudflare)
```
