## 二、 基础属性与减伤换算口径

基础数值测算依据王者荣耀正式服通用规则：

1. **穿透先后顺序与抗性减免**：伤害计算优先扣除固定物理/法术穿透，再按百分比穿透比例折算目标剩余实际抗性，之后代入减免公式：

   $$\text{受击净伤害} = \text{原始总伤害} \times \frac{602}{602 + \text{目标实际抗性}}$$

2. **物理 / 法术有效生命（EHP）**：综合最大生命与防御免伤率评估承伤能力：

   $$\text{物理有效生命 (EHP)} = \text{最大生命} \times \left(1 + \frac{\text{物理防御}}{602}\right)$$

3. **冷却与攻速规则**：英雄满级技能基础冷却与铭文、装备冷却缩减叠加，严格执行 `40%` 冷却缩减上限；普攻频率按 S30 赛季后移除离散攻速阈值档位的连续线性机制与英雄 1 级自带攻速换算。

## 五、 本地构建说明

公开仓库仅使用 Python 3.8+ 标准库，无需安装额外第三方运行时依赖：

```bash
# 1. 构建全部 6 卷公开版 Markdown 战术知识库 (output/)
python build.py --kb

# 2. 按需单独构建指定卷（可选：--skills / --relations / --builds / --item / --arcana / --rules）
python build.py --skills --item
```
